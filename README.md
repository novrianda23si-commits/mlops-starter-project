# MLOps Starter Project

## Deskripsi

Project praktikum MLOps untuk membangun fondasi project,
Git, GitHub, dan environment Python yang reproducible.

## Struktur Project

- frontend/ : bagian antarmuka aplikasi
- backend/ : API dan business logic
- model/ : kode dan artefak machine learning
- data/ : data project
- tests/ : pengujian
- docs/ : dokumentasi

## Tech Stack

- Python
- Git
- GitHub
- Pandas
- NumPy
- Scikit-learn
- FastAPI
- Uvicorn
- Pytest
